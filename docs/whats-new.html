What's new in Nineteen

Major features added in the latest release.

Everything from the original Nineteen is still here, with the same look and feel: grouping and color-coding, sorting, split view, counts, search, the high-frequency word list, pinnable viewers, zoom, and saving as HTML or PNG. The features below are new.

Tagging and organizing data

  • Tagging: Add tags to any data item from its pinned viewer, with suggestions from existing tags. Tags are stored alphabetically in a "Tags" column, so they save and export with the data.
  • Tag-aware grouping and search: Grouping or coloring by tags uses each data item's tag combination, still one box per data item. Tag options can leave tags out or focus on one, and search matches whole tags.
  • Reorderable legend: Drag legend entries, or use Alt + arrow keys, to put values in a meaningful order, such as Not at all satisfied → Extremely satisfied. Colors, split bands and A–Z rows all follow the new order.

Layout and readability

  • Split view headers: Split view gets a header row showing each band's value and, with counts on, its total. Labels wrap onto up to 3 lines, only the narrowest columns widen, and labels turn 90° only when many columns are narrow.
  • Compact toolbar: On narrow screens, toolbar buttons shrink to icons so everything fits. "Analyze with AI" sits at the end of the toolbar, with its panel opening directly underneath.

Sizing and fit

  • Boxes that reshape to fit your screen: Data boxes no longer have to be square. With Stretch to fit, they become wider or taller rectangles so the whole dataset fills the window, and they resize automatically as the window changes or you regroup.
  • Sticky Best fit: Best fit keeps square boxes sized to the window as you resize or regroup, until you zoom.
  • Settings dialog: Separate smallest and largest limits for box width and height, a Stretch to fit default, and an opt-in "Remember settings on this device". Changes preview live and only apply when you save.

Saving and export

  • Spreadsheet and CSV downloads: Save the dataset, including tags and AI-added columns, as .xlsx or CSV, alongside the existing HTML and PNG options.

AI analysis

  • Copy prompt for AI: Builds a ready-made analysis prompt (themes, group comparisons, quotes, coding scheme, summary) with your data, to paste into any AI assistant. Nineteen sends nothing.
  • Ask your data: Chat with Claude or ChatGPT about your data using your own API key. Answers cite data items, and clicking a citation highlights those items and opens their viewer.
  • AI auto-coding: The AI assigns every data item to one of your categories, or suggests categories first. The result becomes a new column you can group, color and search by, with an optional reason column.
  • Data sharing controls and consent: Choose exactly which data items and columns any AI tool sees, with a token estimate. Nothing is sent until you confirm, and API keys stay in memory unless you choose to remember them.
